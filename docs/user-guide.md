# NodePilot v1.6.3 使用教程

本教程只介绍当前最新版 **v1.6.3**，按软件中的实际操作顺序编写。

NodePilot 在 Windows 上通过 SSH 管理 Debian VPS，支持部署 3x-ui、VLESS REALITY Vision 与 Hysteria2（HY2）。左侧设置参数，右侧显示实时日志、进度和耗时；点击板块标题可展开或收起。顶部可切换明亮 / 暗色主题，软件会记住选择。

## 1. 准备并打开软件

| 项目 | 要求 |
| --- | --- |
| 电脑 | Windows 10 / 11 x64 |
| VPS | Debian 12 x86_64，支持 root SSH 登录 |
| 连接信息 | 当前服务器地址、实际 SSH 端口、用户名、密码或私钥 |
| 部署组件 | 固定版本 3x-ui v3.9.0；节点测试使用 Xray 26.9.30 |

下载 `NodePilot-v1.6.3-Windows-x64.zip`，**完整解压**后双击 `NodePilot.exe`。保留旁边的 `_internal` 文件夹，不要只移动 EXE；无需安装 Python。

启动时确认 VPS 已安装 Debian 12 x86_64，再点击“已确认，继续”。已经安装好此系统的服务器无需重装。Debian 12 是本软件当前支持范围，并非 3x-ui 的通用最低系统要求。

## 2. 连接服务器与保存密码

在“一键部署 → 服务器连接”填写服务器名称、地址、SSH 端口和用户名。SSH 端口按服务商提供的信息填写，不一定是 22；地址和端口不预填任何个人服务器信息。密码登录时填写 SSH 密码，私钥登录时选择自己的私钥文件。点击“测试连接”，成功后再开始部署。

勾选“记住密码 · 本机加密保存”，成功登录后会使用 Windows DPAPI 加密保存密码。下次从顶部“已保存服务器”选中同一服务器与用户名，可以直接连接。安装包没有内置 VPS 密码。

- 保存的密码绑定当前 Windows 用户，位于 `%LOCALAPPDATA%\NodePilot`，不会随便携包共享到其他电脑。
- 认证失败不会覆盖先前成功保存的密码。重装服务器后密码改变，输入新密码并成功登录一次即可更新。
- “清空连接信息”只清空输入；“清除这台服务器保存的密码”或列表中的“清除密码”删除密码缓存。
- 取消“记住密码”并成功登录，也会清除这台服务器对应的保存密码。
- 删除服务器列表记录会删除其保存密码，不会删除 VPS、节点或本机加密部署结果。

软件默认自动更新服务器身份记录，重装后的指纹变化会写入日志。重装后 IP、SSH 端口或密码改变时，需填写当前信息。

需要人工核对时，勾选“连接前核对服务器身份（可选）”。首次连接或指纹变化会显示确认窗口；在服务商网页控制台核对后点击“信任并继续”。取消则保留原身份记录，不发送登录密码。

## 3. 设置协议、端口与面板账号

展开“节点与端口”，选择 VLESS、HY2 或同时创建两种协议。

| 设置 | 操作 |
| --- | --- |
| 面板端口 | 显示生成的端口，可手动输入或点击随机图标更换 |
| VLESS 端口 | TCP 端口，按部署结果放行 |
| HY2 端口 | UDP 端口，按部署结果放行 |
| 面板账号 | 手动输入，支持 1–64 位英文字母、数字或 `_ . @ -` |
| 面板密码 | 可手动输入、随机生成、显示或隐藏，要求 8–72 UTF-8 字节 |

面板账号密码与 SSH 登录信息分别设置。面板密码随加密部署记录保存，不写入公开参数或实时日志。填写已部署服务器后，软件读取本机对应记录并显示已有端口；部署重试保留原端口、身份和账号密码。

TCP BBR 模式可选“保持当前设置”“启用系统内核 BBR”或“安装 byJoey BBRv3”。保持当前设置不会修改 TCP 参数；系统内核选项不更换内核；BBRv3 安装后需要另行重启 VPS 并检查状态，详见下方 BBR 管理。

勾选“配置本机端口规则”后，软件通过 SSH 配置服务器防火墙。服务商外部安全组仍需在后台放行。

### 手动日期与流量

填写 VPS 续费日期、节点到期时间、可分配流量和服务商流量重置日，日期按北京时间。

- 续费日期供参考，只有选择作为节点到期时间才限制用户；重置日只作记录，不会自动清零。
- 0 表示不限流量；1 GB = 1024³ 字节，1 TB = 1024 GB。
- 同时创建两种协议时，总额度默认平均分配，也可分别指定；有限总额度下合计不能超出预算。
- 部署前预览并确认限额。重试不会覆盖已有用户额度；后续修改使用服务器维护页。

这些是手动节点限额，软件不会自动读取 RakSmart 的账单日期或剩余流量。

## 4. 选择证书方式

展开“域名与证书”。勾选 HY2 后，必须选择证书方式并点击“确认部署证书设置”；未确认时点击部署，软件会提示并定位到此板块，不开始安装。

| 方式 | 填写内容 | 用途 |
| --- | --- | --- |
| 自签证书 · 固定指纹 | 无需域名 | HY2 通过证书指纹验证；面板使用 HTTP IP 链接 |
| 域名证书 · 自动申请 | 只填写访问域名 | 面板启用 HTTPS；启用 HY2 时共用该证书 |

修改证书方式或域名后需重新确认。确认设置并不代表已经签发，证书在部署或应用证书操作时申请。

仅部署 VLESS REALITY 且没有域名时，可以直接部署；此协议不需要自己的域名证书。仅部署 VLESS 也可以配置域名证书，用于面板 HTTPS。

自签 HY2 链接包含 `pinSHA256`，导入客户端时保留此指纹。自签证书不能替代浏览器信任的面板 HTTPS 证书。域名模式无需填写证书联系邮箱或 Cloudflare Token。

## 5. 从准备域名到申请证书

软件“域名配置教程”和“从添加域名开始”提供逐步说明及相关页面入口。以下统一使用 `example.com`、`node.example.com` 作为示例，请替换成自己的域名。

### 5.1 准备域名

没有域名时，在注册商搜索并购买域名，完成账户和邮箱验证。接收他人转来的域名时，确认域名在自己的账户内，且可以修改名称服务器。域名注册需要付费，Cloudflare Free 套餐可免费使用。

### 5.2 添加到 Cloudflare

注册或登录 Cloudflare，选择“添加域 / Add a domain → 连接域”，输入根域名 `example.com`，不要填写 `node.example.com` 或带 `https://` 的网址。选择 Free 套餐，核对导入的 DNS 记录；用于邮箱时保留 MX、SPF、DKIM、DMARC 等记录。

### 5.3 修改名称服务器并等待激活

复制 Cloudflare 为此域名分配的两条名称服务器（NS）。在注册商“域名管理 → 名称服务器 / Nameservers → 自定义”中替换并保存，不能套用其他域名的 NS。

若已启用 DNSSEC，先在注册商关闭并移除旧 DS，激活后再重新配置。回到 Cloudflare 概述，等待状态变成“Active / 已激活”；可以点击检查名称服务器。长时间未激活时，核对 NS 拼写、是否只保留分配的两条，以及是否残留旧 DS。

### 5.4 添加访问域名解析

进入“Cloudflare → 对应域名 → DNS → 记录 → 添加记录”：

| 字段 | 填法 |
| --- | --- |
| 类型 | A |
| 名称 | 例如 `node`，得到 `node.example.com` |
| IPv4 地址 | 当前 VPS 的 IPv4 地址 |
| 代理状态 | 关闭小橙云，选择“仅 DNS”的灰云 |
| TTL | 自动 |

保存后，将完整的 `node.example.com` 填入软件“访问域名”，点击“检查域名解析”。不要保留指向其他服务器的同名 A；没有配置 IPv6 时删除不适用的同名 AAAA。保留仍在使用的其他 DNS 记录。

灰云只解析地址，节点流量直连 VPS，不改变 CN2 或其他线路。Cloudflare 普通橙云不用于当前软件的 VLESS REALITY TCP 或 HY2 UDP 节点。

### 5.5 放行证书验证端口

在服务商安全组添加入站 **TCP 80**，来源 `0.0.0.0/0`，最小和最大端口均填写 `80`，保存并绑定此 VPS。本机防火墙也需允许 TCP 80；勾选本机规则时软件会配置。

TCP 80 用于 HTTP-01 证书申请及自动续期，需要持续保留。面板、节点和 SSH 不可占用验证 TCP 80；已有其他服务占用时，软件会提示冲突，不会停止已有服务。

### 5.6 确认并申请

选择“域名证书 · 自动申请”，填写访问域名、检查解析并确认部署证书设置，再开始部署。软件使用 acme.sh 3.1.6 和独立 HTTP-01 验证申请证书，使用无邮箱 Let’s Encrypt 账户。签发后生成 HTTPS 面板链接，启用 HY2 时共用证书。

证书每天自动检查续期。解析匹配不代表 TCP 80 已放行；失败时按日志核对安全组、本机防火墙、端口占用、CAA 和 CA 验证结果。软件不会静默回退为 HTTP 域名链接。

## 6. 部署、放行端口与导入节点

参数确认后点击“开始一键部署”，右侧实时显示执行情况。完成后切换到“节点与端口”，查看“部署结果”。

- 面板链接、账号、密码各有复制图标，点击显示“已复制”。
- 没有域名时，面板链接为 `http://服务器IP:面板端口/安全路径/`；浏览器提示不安全，登录信息未加密。
- 域名证书签发成功后，链接为 `https://访问域名:面板端口/安全路径/`。
- 公网面板链接可在其他电脑打开，关闭 NodePilot 不影响访问；需先放行实际面板 TCP 端口。

### RakSmart 安全组

SSH 可以修改服务器本机规则，无法修改服务商外部安全组。请按部署结果中的精确清单操作：

1. 登录 RakSmart 客户中心，打开“产品管理 / 我的服务 → 对应 VPS → 安全组”；公有云产品入口可能在“我的服务 → 公有云 → 安全组”。
2. 保留当前实际 SSH 端口的入站 TCP 规则。
3. 添加 VLESS 入站 TCP、HY2 入站 UDP，以及公网面板入站 TCP；只添加实际启用的项目。
4. 每条来源填写 `0.0.0.0/0`，最小和最大端口均填写实际端口；域名证书另需持续保留 TCP 80。
5. 保存并确认安全组已绑定此服务器，再测试节点与面板访问。

已有 UFW 时，软件按实际端口添加本机规则；已有其他 nftables 输入链时会提示核对，不覆盖原策略。没有其他输入链时，仅管理独立的 `inet nodepilot` 表并保留 SSH。

在 3x-ui 修改端口或创建节点后，点击“同步面板现有端口”，更新本机规则和安全组清单，再同步修改服务商规则。此操作不会自动关闭旧端口或删除其他节点。

### v2rayN 导入

点击“测试两种节点”，确认连接后复制节点链接，在支持对应协议的 v2rayN 中从剪贴板导入。HY2 客户端需支持证书 SHA-256 固定，使用匹配的 Xray 或支持 `pinSHA256` 的 Hysteria2 核心。

软件内置节点测试使用 Xray 26.9.30，不依赖已安装的 v2rayN，也不会修改系统代理。

## 7. 已部署后添加域名或修改账号

填写已部署服务器的 SSH 信息，测试连接。软件读取此电脑上对应的加密部署结果，在“节点与端口”显示面板与节点信息；点击“打开面板”使用当前入口。

### 添加域名

完成上述 DNS 和 TCP 80 设置，在“一键部署 → 域名与证书”输入访问域名，点击“给现有面板 / HY2 应用域名证书”。仅部署 VLESS 的服务器也可以启用面板 HTTPS，**无需重新部署节点**。“服务器维护 → 防爆破 → 配置现有面板 HTTPS”也会带到此设置。

证书与入口变更可能重启面板，节点可能短暂断开；账号、节点身份和端口保留。更换 VPS 地址时需要独立更新 DNS。

### 修改面板账号密码

在“服务器维护 → 面板账号与密码”修改首个管理员。软件先备份数据库，再调用官方 CLI 修改并回读验证，成功后更新部署记录。此操作与 SSH 密码分别管理。

## 8. 服务器维护

维护页左侧板块可折叠，右侧持续显示日志，操作会注明目标服务器。

| 板块 | 可用操作 |
| --- | --- |
| 服务器概览 | 查看时间、在线时长、CPU、负载、内存、磁盘、内核、服务与后台任务 |
| 服务与日志 | 重启核心、面板或 VPS；读取日志、导出诊断记录 |
| 端口与网络 | 检查监听和防火墙、测试节点、限量测速、同步端口、复制安全组清单 |
| 防爆破 | 设置 SSH 封禁和白名单、查看统计、单 IP 解封、进入面板 HTTPS 设置 |
| BBR 管理 | 查看算法与版本依据，启用系统 BBR、安装 BBRv3、重启应用或恢复参数 |
| 面板账号与密码 | 修改面板管理员账号和密码 |
| 日期与流量 | 读取用户，修改到期日期、额度、启用状态或重置已用流量 |
| 域名与证书 | 查看有效期、剩余天数和续期结果；更新域名证书或自签证书 |
| 备份与恢复 | 创建、列出、下载和恢复备份 |
| 清理 | 预览并删除本软件安装缓存；确认后清理超过 14 天的 systemd 日志 |

限量测速比较本机、VPS 与节点的 HTTPS 下载，每条路径最多 4 MiB，双协议总测试最多 16 MiB。短测不代表最高带宽；TCP RTT 和重传来自 VPS 所有 TCP 连接。

修改用户限额保留身份、链接和已用流量，流量重置是单独操作。相对到期时间及多个入站共享用户的清零，请在面板核对。更新自签证书后，需要重新导入带新指纹的 HY2 链接。

## 9. SSH 防爆破与统计

打开“服务器维护 → 防爆破”，设置失败次数、观察时间、首次封禁时长、重复尝试延长封禁和可选白名单，再点击“启用 / 更新 SSH 防爆破”。

默认规则：10 分钟内失败 5 次，首次封禁 1 小时；重复尝试按 1 小时、24 小时、7 天递增。修改首次时长后，后续递增按该时长计算并受上限约束。界面可选 15 分钟、1 小时、24 小时、7 天、30 天或永久；永久封禁需要手动解封。

软件保护当前实际 SSH TCP 端口，自动将当前管理连接来源 IP 加入白名单，不修改 SSH 登录方式和节点端口；其他 Fail2ban 规则保留。使用固定管理 IP 时，可额外加入白名单。

组件就绪时直接检查；需要安装时，软件处理 Debian 12 仓库更新与依赖。支持 systemd SSH 日志，仅在确认是 Debian 默认配置时添加兼容设置；自定义日志配置不会自动覆盖。应用前校验规则，失败时输出诊断并尝试恢复原配置。

- “停用 SSH 防爆破”：停用本软件规则并解除其封禁，保留统计历史。
- “恢复上一次规则”：恢复上一份已保存规则，继续加入当前管理来源白名单。
- 单 IP 解封：选择目标，确认后解封并回读状态。
- 已无法 SSH 登录时，使用服务商网页控制台解封。

### 查看统计项

统计位于“防爆破”内部，支持今天、最近 7 / 30 / 90 天，日期按北京时间。

| 指标 | 含义 |
| --- | --- |
| 登录失败 IP | 所选时间段发生失败登录的去重 IP 数 |
| 失败次数 | 所选时间段失败登录的次数 |
| 当前封禁 IP | 当前仍在封禁中的 IP 数 |
| 所选时间段封禁次数 | 时间范围内的封禁次数，重复封禁分别计数 |
| IP 明细 | 每个 IP 的失败次数、封禁次数、最近时间与状态 |

可以手动刷新、导出 JSON，或勾选“每 30 秒自动刷新”；自动刷新仅在此板块展开且没有其他任务时执行。明细最多显示 200 行，汇总统计全部 IP。

服务器每分钟采集一次，历史最多保留 90 天。关闭软件或重启服务不会清空历史；重装 VPS 会丢失未另行保存的数据。统计来自本软件 SSH 规则日志，不统计 3x-ui 登录尝试；失败登录不一定是恶意攻击，已经删除的日志不能补回。

## 10. 查看和管理 BBR

在“服务器维护 → BBR 管理”点击“刷新当前 BBR 状态”，查看运行内核、TCP 算法、模块版本、系统默认队列、实际出站网卡队列与识别依据。

优先读取模块版本。原版 Debian 12 的 6.1 模块没有版本信息时，软件核对 Debian 包来源、内核文件和包校验记录后识别 BBRv1；未知或修改过的内核显示“版本未确认”。安装、待重启与实际生效分别显示。

### 安装 byJoey BBRv3

使用 [byJoey/Actions-bbr-v3](https://github.com/byJoey/Actions-bbr-v3) 的标准内核，固定版本 `x86_64-7.2.9`，校验发布包 SHA-256。只安装 linux-image 包，保留现有内核，不运行交互菜单、Max 模式或自动更新命令。

安装后点击“重启以应用 BBRv3”，待 VPS 重启并重新连接，再刷新状态。只有运行内核匹配、BBR 模块版本为 3、TCP 算法为 `bbr` 且队列为 `fq`，才显示生效。容器、无 GRUB、未确认 Secure Boot 的 UEFI 环境或空间不足时停止安装。

“恢复 BBR 参数”只恢复原 TCP 参数，不卸载或回退内核。新内核启动异常时，可以从服务商控制台选择保留的原内核。

**Linux BBR 作用于 TCP，HY2 的 QUIC 拥塞控制由协议核心管理。** 安装 TCP BBRv3 不会替换 HY2 内部算法。

## 11. 备份、恢复与继续部署

服务器备份保存在 `/var/lib/nodepilot/backups/时间编号`，包含面板数据库、部署记录、证书、ACME 配置与账户、续期任务、本机端口规则和 TCP 参数。

下载的 `.npbackup` 使用独立密码加密并校验，可在另一台 Windows 电脑读取。备份密码至少 8 位，软件不保存此密码，请妥善保管备份与密码。

恢复前检查完整性、面板版本与端口冲突；有现有部署时先创建备份。恢复时面板与节点会中断。原服务器重装 Debian 12 后，可以安装固定组件并恢复数据库、证书与续期任务，再检查服务、监听与实际连接。

恢复不会自动安装 BBRv3 内核，需要单独安装并重启确认。直接恢复使用原服务器地址，换 IP 时需另行配置 DNS。

部署使用服务器检查点。“停止等待”不会强行结束已开始的安装或后台任务。重新连接后在维护页查看任务，再“继续未完成部署”，沿用已有协议、端口、账号与身份。

软件保护非本软件管理的已有面板；不提供任意版本升级、服务商 API 自动放行安全组或整机系统回滚。
