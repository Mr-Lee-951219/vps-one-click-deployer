# NodePilot 节点部署助手

Windows 10/11 x64 桌面程序，支持明亮与暗色主题，延续 Apple / Microsoft 风格。首版支持 Debian 12 x86_64、3x-ui v3.9.0、VLESS REALITY Vision 与 HY2。配套测试核心为官方安装包内的 Xray 26.9.30。

1.6.3 使用顶部导航、左侧可滚动参数和右侧常驻输出窗口。切换功能时仍能看到任务日志、步骤进度和已用时间。日志可暂停自动滚动、清空、复制与导出。新版沿用原布局，采用浅灰底、白色圆角卡片、柔和阴影和玫红强调色；左侧三个板块默认收起，点击标题展开，再次点击收起。证书选项在板块内展开并推动后续内容，不遮挡输入框。面板与节点端口启动时直接显示随机生成的数值，可手动填写或点击随机图标更换；服务器地址和 SSH 端口每次打开均为空。填写已部署服务器后，软件会读取本机记录并显示原端口，避免重试更换已有端口。

## 自动生成面板链接（1.5.1）

一键部署完成后，在“节点与端口 → 部署结果”直接显示可跨电脑访问的面板链接、账号和密码，三项右侧均有独立复制图标，点击后显示绿色勾及“已复制”提示。维护页的公网面板设置板块已移除。

没有域名：留空访问域名，自动生成 `http://服务器IP:面板端口/安全路径/`。HTTP 浏览器登录信息不加密；当前版本未接入可信 IP 证书。填写域名：选择“域名证书 · 自动申请”，只填访问域名。先把域名灰云 A 记录指向 VPS，并放行 TCP 80；软件自动签发并生成 `https://填写的域名:面板端口/安全路径/`。仅部署 VLESS 时同样可填写此证书设置。HY2 与面板共用已签发的证书和域名，各自使用独立端口；自签 HY2 证书不会用于浏览器面板。

域名需已在 Cloudflare 激活，手动添加仅 DNS（灰云）A 记录指向 VPS IPv4；软件检查解析，不代替用户修改 DNS。没有配置 IPv6 时清除不适用的同名 AAAA，避免证书验证连错服务器；现有邮箱 DNS 记录保持。证书设置及教程已移除证书联系邮箱和 Cloudflare Token，无邮箱注册 Let’s Encrypt，使用 HTTP-01 验证。旧版 DNS 验证证书及其服务器上的续期凭据继续兼容。

已有服务器无需重新部署：输入连接信息，在部署结果点击“打开面板”。旧的本机入口会自动备份并切换为公网入口；已有正式域名证书则复用，否则使用 IP。面板账号密码、节点和端口保留；配置会重启面板，节点可能短暂断开。软件通过 SSH 检查面板接口及公网监听，失败时恢复原入口。日常接口管理仍通过 SSH，HTTPS 校验服务器证书指纹。已有公网入口直接打开。

RakSmart 云安全组仍需放行实际面板入站 TCP 端口，来源 `0.0.0.0/0`，规则需绑定到 VPS。该端口自动加入结果放行清单；勾选本机端口规则时也自动处理服务器防火墙。已有本机防火墙若无法自动修改，实时日志会显示需要核对的规则。软件生成链接并验证本机接口不能证明云安全组已放行。开放后其他电脑可直接登录，关闭 NodePilot 不影响访问。面板账号密码和随机安全路径仍需妥善保管。

公网设置、证书和续期凭据随加密备份保存，直接恢复原 VPS 支持保留入口。换 IP 的迁移需另行配置 DNS。公网面板仍需账号密码。[3x-ui 官方证书与监听设置](https://github.com/MHSanaei/3x-ui/blob/v3.9.0/main.go)

## 打开软件

便携包请完整解压，然后双击 `NodePilot.exe`。不要只移动 exe；旁边的 `_internal` 文件夹是运行所需文件。无需安装 Python。

每次打开软件会显示服务器系统提示。确认服务器是 Debian 12 x86_64 后点击“已确认，继续”；已有 Debian 12 无需重装。这是本软件当前支持范围，并不是 3x-ui 的通用最低版本要求。

可以手动填写服务器，也可在顶部“已保存服务器”选择连接。勾选“记住密码 · 本机加密保存”，密码登录成功后会使用 Windows DPAPI 加密保存；下次选择同一服务器和用户名可直接连接。密码由你输入，安装包没有内置密码。认证失败不会覆盖以前成功保存的密码；重装后密码更换时，请输入新密码并成功连接一次。

加密密码绑定当前 Windows 用户，保存在 `%LOCALAPPDATA%\NodePilot`，不会写入明文服务器列表、日志或源码包。切换服务器或用户名时，先清空当前密码，再读取对应保存的密码。私钥文件及 Cloudflare Token 不保存在此密码缓存中。“清空连接信息”只清空当前输入；可在连接板块或顶部列表点击“清除密码”删除保存的密码。取消“记住密码”并成功登录后，也会清除该服务器的保存密码。新版启动只清理旧格式缓存，保留新版加密密码。

默认自动记录服务器身份；重装系统导致 SSH 指纹变化时，软件会更新这台服务器和对应端口的记录并自动重连，不再弹出指纹错误。变化会写入日志。请填写服务器当前的 IP、SSH 端口和登录密码；重装后端口或密码变化仍需更新输入。自动模式不要求人工核对指纹。

若需要人工核对，可在“服务器连接”勾选“连接前核对服务器身份（可选）”。严格模式下，首次连接和指纹变化时会显示确认窗口；点击“信任并继续”即可保存当前身份并继续本次操作，点击“取消”则保留原记录且不发送登录密码。窗口提供从服务商网页控制台核对的方法。

## 已部署的服务器

展开“服务器连接”，填写你的服务器地址和 SSH 端口，软件会读取这台电脑上对应的加密部署结果。输入 SSH 密码后，在“节点与端口”点击“打开面板”。填写内容均由你提供，程序不预设任何服务器地址或 SSH 端口。

面板用户名、密码、面板链接、节点链接和二维码在软件“节点与端口”页显示。关闭软件不影响公网面板链接。

## 放行端口

部署时会按实际端口配置服务器本机规则。**云安全组需要在 RakSmart 客户中心设置，SSH 不能修改服务商的外部规则。** 软件当前提供精确清单和教程，不会显示虚假的云安全组自动放行成功。

1. 登录 RakSmart 客户中心，打开“产品管理 / 我的服务”→对应 VPS→安全组。公有云产品可能是“我的服务→公有云→安全组”。
2. 保留你实际使用的 SSH TCP 端口规则。
3. 按软件清单添加 VLESS 入站 TCP，最小和最大端口都填写实际 VLESS 端口，来源 `0.0.0.0/0`。
4. 按软件清单添加 HY2 入站 UDP，最小和最大端口都填写实际 HY2 端口，来源 `0.0.0.0/0`。
5. 保存并确认安全组已绑定此服务器。仅监听服务器本机的面板端口不用开放公网。
6. 在软件中点击“测试两种节点”，或将链接导入 v2rayN。

服务商的云规则与本机防火墙是两层。已有 UFW 会按实际端口添加规则；已有其他 nftables 输入链时，软件保留它们并提示手动配置，避免覆盖现有策略。没有其他输入链时只管理独立的 `inet nodepilot` 表，保持原有 SSH 可用。

在 3x-ui 中修改节点端口或新建节点后，点击“同步面板现有端口”，更新本机规则及云安全组清单，再更新 RakSmart 后台规则。同步不会删除其他节点、清空防火墙或自动关闭旧端口。

## HY2 证书设置

勾选 HY2 后，必须先在“HY2 证书”区域选择证书方式并点击“确认 HY2 证书设置”。没有确认就点击部署时，软件会弹出提示并滚动到证书区域，不会连接服务器或开始安装。自签模式无需填写域名；域名模式只填写访问域名，提前准备灰云解析和 TCP 80。更改证书设置后需要重新确认；取消勾选 HY2 时无需确认。确认域名证书设置不代表已签发，证书会在部署时申请。

教程统一使用 example.com / hy2.example.com 作为示例，请替换为你自己的域名。

## Cloudflare 与域名证书

完整教程在软件“域名配置教程”中，从注册 / 接收域名开始。若你的域名同时用于邮箱，保留 MX、SPF、DKIM、DMARC 等邮箱记录。

节点解析使用灰云“仅 DNS”。Cloudflare 普通橙云不能承载 HY2 UDP，也不能直接承载当前软件的 VLESS REALITY TCP 连接。灰云只解析地址，流量直连 VPS，不经过 Cloudflare 代理，不改变 CN2 线路；DNS 查询可能影响首次连接耗时，但不会为持续数据传输增加一条代理路径。当前 VLESS REALITY 无需自己的域名证书，证书设置用于面板 HTTPS 和 HY2。

只填写访问域名，检查解析后可以首次部署，也可以点击“给现有面板 / HY2 应用域名证书”，仅部署 VLESS 的已有服务器同样可用，无需重新部署节点。软件使用 acme.sh 3.1.6 的独立 HTTP-01 验证，Let’s Encrypt 无邮箱账户注册，需在云安全组及本机防火墙持续放行 TCP 80。软件会把验证端口加入清单，启用本机规则时自动配置；SSH 不能替代云安全组操作。面板、节点和 SSH 不可占用验证 TCP 80；已有其他服务占用时停止配置并提示，不关闭该服务。每日 systemd 任务检查续期，新证书不读取 DNS 凭据。域名签发失败时核对解析、防火墙、TCP 80、CAA 及 CA 验证结果，软件不会默默回退成不安全的域名链接。

**真实域名签发与续期尚未完成实测**。正式域名模式不附加 insecure。自签模式的 HY2 链接同时包含证书指纹，请不要删除 pinSHA256。

## v2rayN

使用官方较新版本，需支持 HY2 与证书 SHA-256 固定。复制软件中的节点链接，在 v2rayN 从剪贴板导入。HY2 可使用匹配的新 Xray 核心，或支持 pinSHA256 的官方 Hysteria2 核心。软件内置测试使用 Xray 26.9.30，不依赖你已安装的 v2rayN，也不会修改系统代理。

## byJoey BBRv3

“安装 BBRv3”使用 [byJoey/Actions-bbr-v3](https://github.com/byJoey/Actions-bbr-v3) 的标准内核，当前固定版本 `x86_64-7.2.9`，下载前后校验发布包 SHA-256。软件适配安装流程，不执行项目的交互菜单、Max 模式或自动更新命令。仅安装该项目的 linux-image 包，不替换 libc 开发包，不卸载当前或旧内核。

选择“安装 byJoey BBRv3”后会在节点配置完成时安装新内核，保留原引导配置与 TCP 参数。软件不会自动重启；部署结果会显示“尚未生效”，在“服务器维护”点击“重启以应用 BBRv3”，稍后点击“刷新当前 BBR 状态”。只有运行内核匹配、BBR 模块版本为 3、TCP 算法为 bbr 且队列为 fq，才显示已生效。容器、无 GRUB、未确认 Secure Boot 的 UEFI 环境或磁盘空间不足时停止安装。

HY2 的 QUIC 拥塞控制由协议核心实现，Linux TCP BBRv3 不会替换 HY2 内部算法。“恢复 BBR 参数”只恢复原 TCP 参数，不卸载新内核；若新内核启动异常，可用服务商控制台选择保留的旧内核。该内核集成已通过离线流程检查及 Debian 服务器上的只读语法检查，尚未在这台服务器实际更换内核或重启验证。

## 已保存服务器

顶部“已保存服务器”显示名称、服务器地址、SSH 端口、密码是否已保存及最近成功连接时间。支持选择连接、修改名称、清除密码和删除列表记录。首次连接成功自动加入；旧版在本机保存的加密部署记录会导入一次。有保存密码时，选中服务器可直接连接；未保存时会提示输入当前密码，也可取消后在连接板块选择私钥。

明文列表只保存连接地址、用户名和手动额度设置；登录密码保存在独立的加密文件中。删除服务器记录同时清除该服务器保存的密码，不删除 VPS、节点或本机的加密部署结果。重新连接会再次加入。

## 手动日期与流量

展开一键部署的“节点与端口”，填写 VPS 续费日期、节点到期时间、可分配流量和服务商流量重置日。日期显示与写入均按北京时间。续费日期只供参考，只有选择作为节点到期时间才限制用户。重置日只作记录，不自动清零。

0 表示不限流量；1 GB = 1024³ 字节，1 TB = 1024 GB，与面板内部字节配额一致。同时创建 VLESS 与 HY2 时，总配额默认平均分配，也可分别指定，有限总配额下合计不可超出总量。单协议获得整个预算。部署前预览并确认，写入新建客户端的到期时间与流量；重试不会覆盖已有用户的限额，请使用维护页修改。

这些数值是手动设置的节点限额，并非 RakSmart 的自动账单或剩余流量。每台服务器单独保存，软件不会自动读取服务商日期、剩余流量或自动月度续费。

## 服务器维护

维护页保留左侧折叠板块与右侧常驻日志，操作标明目标服务器。

- 概览：服务器时间、在线时长、CPU 核数与负载、内存、磁盘、系统内核、面板服务、实际监听与后台任务状态。
- 服务与日志：重启核心、重启面板、重启 VPS、读取最近日志、导出右侧诊断记录。
- 端口与网络：读取防火墙与监听，测试节点真实 HTTPS 流量，限量测速与 TCP 重传诊断，同步面板实际端口与本机规则，复制云安全组清单。
- 防爆破：设置 SSH 自动封禁与白名单，配置面板 HTTPS；内部查看历史统计、当前封禁、解封时间及 IP 明细，支持解封和导出。
- BBR：读取当前 TCP 算法、模块版本、运行内核及队列。无法可靠确认版本时明确显示“版本未确认”。byJoey 已安装、当前生效、待重启分别显示。HY2 QUIC 单独读取；可保持当前设置、启用当前内核 BBR 或安装 byJoey BBRv3。
- 日期与流量：刷新真实面板用户，选中后修改固定日期、总配额、启用状态或单独重置流量。修改限额保留身份、链接和已用流量。相对到期时间和多个入站共享用户的清零请从面板核对操作。
- 域名与证书：为现有面板 / HY2 添加域名证书，查看剩余天数、有效期与续期任务结果，续期域名证书或更新自签证书。更新自签证书后须重新导入带新指纹的 HY2 链接。
- 备份与恢复：创建、列出、下载服务器备份，恢复服务器备份或本机加密备份；支持同一服务器重装 Debian 12 后恢复。
- 清理：精确预览本软件安装包缓存后删除；另可确认清理整个服务器 systemd 日志库中超过 14 天的日志。

## 备份、恢复与重试

备份保存在 /var/lib/nodepilot/backups/时间编号，包含面板数据库、部署记录、证书、ACME 账户与配置、Cloudflare 续期凭据、续期任务、本机端口规则和 TCP 参数文件。下载的 .npbackup 使用独立密码加密并校验，可以在另一台 Windows 电脑读取；至少 8 位的备份密码请妥善保存，软件不保存该密码。

恢复前检查完整性、面板版本和端口冲突；有现有部署时先创建完整备份。恢复期间面板与节点会中断。新系统自动安装固定的 3x-ui v3.9.0 后恢复数据库、证书与续期任务，再读取服务、监听并测试实际节点连接。恢复不自动安装 BBRv3 内核，须单独安装并重启验证。当前版本直接恢复原服务器地址；Cloudflare 域名迁移到新 IP 需独立配置，软件不会悄悄修改域名。

安装步骤有服务器检查点；电脑连接断开后，已启动的安装任务仍会继续。重新部署沿用原端口和身份。概览会显示后台任务结果。恢复原 TCP 参数不会卸载或回退内核。

已有非本软件管理的面板会被保护。当前版本不提供任意版本升级、RakSmart API 安全组修改或整机系统回滚；服务商安全组仍需按实际 TCP / UDP 端口在后台放行。
